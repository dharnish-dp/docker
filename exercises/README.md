# Docker Real-World Projects

Five complete projects from beginner to production.
Each project is self-contained — all files provided, just follow the README inside each folder.

---

| Project | Stack | Teaches |
|---|---|---|
| [01-selenium-test-suite](01-selenium-test-suite/) | Python + Selenium + Chrome | Containerized browser automation |
| [02-fastapi-postgres-redis](02-fastapi-postgres-redis/) | FastAPI + PostgreSQL + Redis | Full API stack with Compose |
| [03-deploy-to-vps](03-deploy-to-vps/) | Docker Hub + Nginx + VPS | Real server deployment |
| [04-cicd-pipeline](04-cicd-pipeline/) | GitHub Actions + Docker Hub | Automated build → test → deploy |
| [05-data-pipeline](05-data-pipeline/) | Python + PostgreSQL + pgAdmin | Scheduled scraper with dashboard |

---

## Recommended Order

1. Start with **01** — runs immediately, no server needed
2. Then **02** — adds database and cache, still local
3. Then **03** — takes your project 02 app live on a real server
4. Then **04** — automates the deployment from project 03
5. Then **05** — standalone data engineering project
